The rules of the folder

Deadline: 5:30 PM sharp

Name your files properly

Every file follows this convention:
[RFP XX][Project Name] Artifact Name V-x.y.z
Files that can't be traced back to a team can't be scored.

📁

One folder for everyone

All 20 teams upload into the same folder — multiple files are welcome, no need to zip anything. Keep each artifact as its own file.

🔁

Same name = replaced

Uploading a file with the same name replaces the older copy — there is no version control. If versions differ (V-1.0.1 vs V-1.0.0), only the latest lands in the index.
